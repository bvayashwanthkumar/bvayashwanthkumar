I'm a Computer Science and Engineering undergraduate at **Lovely Professional University**, with a CGPA of **8.72/10**, interested in the intersection of software engineering, data analytics, and artificial intelligence.

My work focuses on understanding data, developing analytical solutions, building predictive machine learning models, and communicating insights through interactive visualizations and dashboards. I enjoy exploring how programming, algorithms, and data-driven approaches can solve practical problems.

### 🚀 What I Do

- **Analyze Data:** Work with Python, Pandas, NumPy, SQL, and exploratory data analysis to discover patterns and meaningful insights.
- **Build Machine Learning Solutions:** Apply data preprocessing, feature engineering, and machine learning techniques to predictive problems.
- **Create Interactive Visualizations:** Use Power BI, DAX, Power Query, Excel, Matplotlib, and Seaborn to turn data into understandable visual stories.
- **Develop Software:** Use Python, Java, C, C++, and SQL to strengthen my programming and problem-solving skills.
- **Work with Databases:** Explore relational database development using MySQL, Oracle Database, Oracle APEX, and PL/SQL.
- **Learn and Experiment:** Continue expanding my knowledge of AI, deep learning, big data technologies, and modern software development tools.

        ↓

### 🎯 What Drives Me

I'm motivated by continuous learning, analytical thinking, and building solutions that have a clear purpose. My goal is to grow as a technology professional who can combine programming, data analysis, and machine learning to solve real-world challenges.

**My philosophy:** Build with purpose. Analyze with curiosity. Improve continuously.
